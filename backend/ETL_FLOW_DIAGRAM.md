## 🔄 二、ETL 执行流程

### 2.1 完整 ETL 流程（T+1 增量）

```
时间：每天凌晨 1:00 - 6:00
时区：Asia/Shanghai

┌─────────────────────────────────────────────────────────┐
│ 01:00  启动 ETL 流程                                      │
│         ↓                                                │
│ 02:00  ODS 层抽取（约 30-60 分钟）                         │
│         - 从 SQLite 读取 T-1 日数据                        │
│         - 插入 MySQL ODS 层表                             │
│         - 添加分区字段 dt=T-1                            │
│         ↓                                                │
│ 03:00  DWD 层清洗（约 30-60 分钟）                         │
│         - 从 ODS 层读取 dt=T-1 数据                        │
│         - 数据清洗和标准化                               │
│         - 关联维度表补充信息                           │
│         ↓                                                │
│ 04:00  DWS 层聚合（约 30 分钟）                            │
│         - 从 DWD 层读取 dt=T-1 数据                        │
│         - 轻度聚合生成事实表                           │
│         - 刷新维度表                                   │
│         ↓                                                │
│ 05:00  ADS 层报表（约 30 分钟）                            │
│         - 从 DWS 层读取 dt=T-1 数据                        │
│         - 按报表口径二次聚合                           │
│         - 生成驾驶舱指标                               │
│         ↓                                                │
│ 06:00  ETL 流程完成                                       │
│         - 记录执行日志                                   │
│         - 发送成功通知                                   │
└─────────────────────────────────────────────────────────┘
```
