# Metabase BI 配置指南

## 📊 Metabase 简介

Metabase 是一个开源 BI 工具，用于：
- 数据可视化
- 仪表板制作
- 即席查询
- 报表分享

## 🚀 快速启动

### 1. 启动 Metabase

```bash
cd /Users/huangqiang/.openclaw/workspace/erp-bi-system
docker-compose up -d metabase
```

### 2. 访问 Metabase

打开浏览器访问：**http://localhost:3001**

首次启动需要 2-3 分钟初始化。

## ⚙️ 初始配置

### 步骤 1：管理员设置

1. 设置管理员账号
   - 邮箱：`admin@erp-bi.com`
   - 用户名：`admin`
   - 密码：`admin123`
   - 姓名：`ERP BI Admin`

2. 设置个人信息
   - 姓名：`演示用户`
   - 邮箱：`user@erp-bi.com`

### 步骤 2：添加数据源

1. 点击 **⚙️ 设置** → **添加数据库**

2. 填写 MySQL 连接信息：
   ```
   显示名称：AI数据融合 数据库
   数据库类型：MySQL
   主机：mysql (Docker 网络) 或 127.0.0.1 (本地)
   端口：3306
   数据库名：erp_bi
   用户名：erp_bi_user
   密码：erp_bi_pass
   ```

3. 点击 **保存**，测试连接

### 步骤 3：同步数据表

1. 进入 **⚙️ 设置** → **数据库** → **AI数据融合 数据库**
2. 点击 **同步数据库架构**
3. 等待同步完成（5 张表）

## 📈 创建报表

### 报表 1：销售 KPI 卡片

1. 点击 **+ 新建** → **问题**
2. 选择 **AI数据融合 数据库** → **sales_orders**
3. 选择 **汇总** → **总和** → 选择 **final_amount**
4. 点击 **可视化** → 选择 **数字**
5. 保存为：**总销售额**

### 报表 2：月度销售趋势

1. 点击 **+ 新建** → **问题**
2. 选择 **sales_orders** 表
3. 按 **order_date** 分组（按月）
4. 汇总 **final_amount** 总和
5. 可视化选择 **折线图**
6. 保存为：**月度销售趋势**

### 报表 3：产品销量排行

1. 点击 **+ 新建** → **问题**
2. 选择 **sales_order_items** 关联 **products**
3. 按 **product_name** 分组
4. 汇总 **quantity** 总和
5. 排序：降序，限制 10 条
6. 可视化选择 **条形图**
7. 保存为：**产品销量 Top10**

### 报表 4：客户订单分析

1. 点击 **+ 新建** → **问题**
2. 选择 **sales_orders** 关联 **customers**
3. 按 **customer_name** 分组
4. 汇总 **order_count** 和 **final_amount**
5. 可视化选择 **表格**
6. 保存为：**客户订单分析**

### 报表 5：品类销售占比

1. 点击 **+ 新建** → **问题**
2. 选择 **products** 关联 **sales_order_items**
3. 按 **category** 分组
4. 汇总 **subtotal** 总和
5. 可视化选择 **饼图**
6. 保存为：**品类销售占比**

## 🔗 分享和嵌入

### 公开链接

1. 进入仪表板
2. 点击右上角 **分享** 图标
3. 开启 **公开链接**
4. 复制链接用于演示

### 嵌入到前端

1. 点击 **分享** → **嵌入到应用**
2. 选择 **嵌入代码**
3. 复制 iframe 代码到 Vue 组件

```vue
<template>
  <iframe
    src="http://localhost:3001/public/dashboard/xxx-xxx-xxx"
    width="100%"
    height="600"
    frameborder="0"
  />
</template>
```

## 🔧 常见问题

### Q1: Metabase 无法连接 MySQL

**解决**：确保 MySQL 和 Metabase 在同一 Docker 网络
```bash
docker-compose up -d mysql metabase
```

### Q2: 中文乱码

**解决**：MySQL 使用 utf8mb4 字符集
```sql
SHOW VARIABLES LIKE 'character%';
```

### Q3: 启动慢

**解决**：首次启动需要初始化 H2 数据库，等待 3-5 分钟
