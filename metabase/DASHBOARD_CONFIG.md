## ⚙️ 数据源配置

### 步骤 1：管理员设置

首次访问需要设置管理员账号：

| 字段 | 值 |
|------|-----|
| 邮箱 | admin@erp-bi.com |
| 用户名 | admin |
| 密码 | admin123 |
| 姓名 | ERP BI Admin |

### 步骤 2：添加 MySQL 数据源

1. 点击 **⚙️ 设置** → **添加数据库**

2. 填写连接信息：

| 字段 | 值 |
|------|-----|
| 显示名称 | AI数据融合 数据库 |
| 数据库类型 | MySQL |
| 主机 | 127.0.0.1 |
| 端口 | 3306 |
| 数据库名 | erp_source |
| 用户名 | root |
| 密码 | root123 |
| SSL | 不使用 |

3. 点击 **保存**，测试连接

### 步骤 3：同步数据表

1. 进入 **⚙️ 设置** → **数据库** → **AI数据融合 数据库**
2. 点击 **同步数据库架构**
3. 等待同步完成（包含 5 张基础表 + 9 个视图）

## 📊 仪表板配置

### 创建仪表板

1. 点击 **+ 新建** → **仪表板**
2. 名称：**ERP 销售分析大屏**
3. 描述：**毕业答辩演示仪表板**

### 添加 KPI 卡片（第一行）

创建 5 个数字卡片：

| 卡片名 | 数据源 | 字段 |
|--------|--------|------|
| 总销售额 | v_kpi_summary | kpi_value (总销售额) |
| 总订单数 | v_kpi_summary | kpi_value (总订单数) |
| 总销售量 | v_kpi_summary | kpi_value (总销售量) |
| 客户总数 | v_kpi_summary | kpi_value (客户总数) |
| 产品种类数 | v_kpi_summary | kpi_value (产品种类数) |

### 添加月度销售趋势图（第二行）

1. **+ 新建** → **问题**
2. 选择 **AI数据融合 数据库** → **v_sales_summary**
3. 选择 **stat_month** 作为 X 轴
4. 选择 **total_amount** 作为 Y 轴
5. 可视化选择 **折线图**
6. 保存为：**月度销售趋势**

### 添加产品销量排行（第三行左侧）

1. **+ 新建** → **问题**
2. 选择 **v_product_top10**
3. 选择 **product_name** 作为 X 轴
4. 选择 **total_quantity** 作为 Y 轴
5. 可视化选择 **条形图**
6. 保存为：**产品销量 Top10**

### 添加品类销售占比（第三行右侧）

1. **+ 新建** → **问题**
2. 选择 **v_category_analysis**
3. 选择 **category** 作为维度
4. 选择 **total_amount** 作为度量
5. 可视化选择 **饼图**
6. 保存为：**品类销售占比**

### 添加客户订单分析（第四行）

1. **+ 新建** → **问题**
2. 选择 **v_customer_analysis**
3. 选择所有字段
4. 可视化选择 **表格**
5. 保存为：**客户订单分析**

## 🔧 常见问题

### Q1: Metabase 无法访问

**检查**：
```bash
docker ps | grep metabase
docker logs erp-bi-metabase
```

**解决**：
```bash
docker-compose restart metabase
```

### Q2: 数据源连接失败

**检查**：
```bash
docker exec erp-bi-mysql mysql -uroot -proot123 -e "SELECT 1"
```

**解决**：确保 MySQL 和 Metabase 在同一网络
