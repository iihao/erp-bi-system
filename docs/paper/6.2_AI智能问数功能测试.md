# 6.2 AI智能问数模块功能测试

## 一、测试概述

AI智能问数模块是系统面向非技术用户的核心功能，支持通过自然语言提问实现数据查询。本节对该模块的四层匹配策略（LRU缓存 → 标准SQL库 → 向量语义匹配 → AI在线生成）进行全覆盖功能测试，共计15个测试用例，覆盖标准SQL库匹配、向量语义匹配、AI在线生成、缓存命中、图表推荐、安全校验、异常处理等核心功能路径。

## 三、核心测试用例详情

### TC-AI-001 标准SQL库精确匹配

| 项目 | 内容 |
|------|------|
| **前置条件** | 标准SQL库中存在question_template="各楼盘认购排行"的记录 |
| **测试步骤** | 1. 用户输入问题"各楼盘认购排行" 2. 系统归一化处理 3. 提取关键词 4. 标准SQL库匹配 5. 执行SQL并返回结果 |
| **输入数据** | "各楼盘认购排行" |
| **预期结果** | ① match_source="标准库命中" ② 不消耗AI token ③ 返回项目认购金额排行数据 ④ 推荐饼图展示 |
| **实际结果** | 标准SQL库命中，执行耗时12ms，返回8个项目认购数据，未消耗token |
| **结论** | 通过 |

### TC-AI-002 向量语义匹配命中

| 项目 | 内容 |
|------|------|
| **前置条件** | 历史向量库中存在"各项目回款趋势"的向量记录 |
| **测试步骤** | 1. 用户输入"各项目的回款趋势如何" 2. 标准SQL库未命中 3. 调用Embedding生成向量 4. 计算余弦相似度 |
| **输入数据** | "各项目的回款趋势如何" |
| **预期结果** | ① match_source="向量匹配" ② 相似度score≥0.78 ③ 返回回款趋势数据 |
| **实际结果** | 向量匹配命中，score=0.856，执行耗时230ms |
| **结论** | 通过 |

### TC-AI-003 AI在线生成SQL

| 项目 | 内容 |
|------|------|
| **前置条件** | 标准SQL库和向量库均未命中 |
| **测试步骤** | 1. 用户输入"今年各区域项目成本预算执行情况" 2. 三层缓存均未命中 3. 构建Schema上下文 4. 调用AI模型生成SQL 5. 约束校验 6. 执行查询 |
| **输入数据** | "今年各区域项目成本预算执行情况" |
| **预期结果** | ① match_source="AI在线生成" ② 生成SELECT语句 ③ 优先使用dws_sales_cost_fact表 ④ 返回预算与实际对比数据 |
| **实际结果** | AI生成成功，token消耗486，使用ads_project_cost_report表，返回预算执行数据 |
| **结论** | 通过 |
