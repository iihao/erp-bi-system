## 关键设计决策

### 1. 设计令牌优先
**决策：** 所有样式使用 CSS 变量（`var(--primary)`, `var(--spacing-4)` 等）

**理由：**
- 确保全站样式一致性
- 便于主题切换和维护
- 减少硬编码值

### 2. SVG 图标系统
**决策：** 使用内联 SVG 图标而非图标库

**理由：**
- 减少外部依赖
- 更好的性能（无 HTTP 请求）
- 可自定义颜色和尺寸
- 支持动画效果

### 3. 响应式断点
**决策：** 移动端优先，768px 和 1024px 两个主要断点

**理由：**
- 覆盖主流设备尺寸
- 移动端隐藏侧边栏，显示汉堡菜单
- 桌面端完整功能展示

### 4. 动画过渡
**决策：** 所有交互元素添加 200ms 过渡动画

**理由：**
- 提升用户体验流畅度
- 视觉反馈更自然
- 使用统一的 cubic-bezier 曲线

### 5. 卡片化设计
**决策：** 使用 el-card 包裹搜索区和表格区

**理由：**
- 视觉层次清晰
- 圆角 + 阴影增强立体感
- 符合现代 UI 设计趋势

### 6. 颜色语义化
**决策：** 功能色使用语义化变量

**理由：**
```css
--success (绿色) - 成功、启用
--warning (橙色) - 警告、待处理
--danger (红色) - 删除、错误、禁用
--info (蓝色) - 信息、普通标签
```
