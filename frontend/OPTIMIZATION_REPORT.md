## 设计决策说明

### 3.1 配色方案
**决策**：采用深蓝色系作为主色调

**理由**：
- 蓝色是企业级软件最常用的颜色，传递专业、可靠、信任感
- SAP、Oracle、微软等企业软件均采用蓝色系
- 深蓝色 (#1E3A8A) 到亮蓝色 (#3B82F6) 的渐变，既有稳重度又有现代感

### 3.2 圆角设计
**决策**：采用中等圆角 (6-12px)

**理由**：
- 过小圆角显得生硬，过大圆角不够专业
- 8px 圆角在专业感和亲和力之间取得平衡
- 卡片使用 12px 圆角，按钮使用 8px 圆角，形成层次

### 3.3 阴影系统
**决策**：多层次阴影，轻度使用

**理由**：
- 阴影用于创建层次感和深度
- 轻度阴影 (shadow-sm, shadow) 用于日常状态
- 中度阴影 (shadow-md, shadow-lg) 用于悬浮状态
- 避免过度使用阴影造成视觉负担

### 3.4 动画原则
**决策**：克制、流畅、有意义

**理由**：
- 动画时长控制在 150-300ms，快速但不突兀
- 使用贝塞尔曲线 (cubic-bezier) 实现自然缓动
- 动画用于反馈用户操作，而非装饰
- 骨架屏动画提升加载体验

### 3.5 响应式策略
**决策**：移动优先，渐进增强

**理由**：
- 基础布局适配移动端
- 平板端增加双栏布局
- 桌面端完整展示所有功能
- 使用 CSS Grid 和 Flexbox 实现灵活布局
