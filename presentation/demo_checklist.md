- [ ] Redis 缓存服务正常

### 账号准备
- [ ] 测试账号：admin / admin123
- [ ] Metabase 账号已配置
- [ ] 确保账号有足够的数据权限

### 数据准备
- [ ] ODS 层数据已同步

- [ ] ADS 层有充足的报表数据
- [ ] 近 30 天销售数据完整
- [ ] 产品、客户数据完整

## 🖥️ 演示流程（5 分钟）

### 第 1 步：登录系统（30 秒）
- [ ] 访问 http://localhost:3000/login
- [ ] 输入账号密码
- [ ] 成功跳转到仪表板

### 第 2 步：仪表板展示（45 秒）
- [ ] 展示 KPI 卡片（总销售额、订单数等）
- [ ] 指向销售趋势图
- [ ] 简要说明图表含义

### 第 3 步：报表浏览（45 秒）
- [ ] 切换到销售报表页面
- [ ] 展示产品排行
- [ ] 展示品类占比
- [ ] 演示日期筛选功能

### 第 4 步：AI 智能问数（90 秒）⭐
- [ ] 进入 AI 问数页面
- [ ] 演示示例 1："上个月销售额最高的产品是什么？"
- [ ] 演示示例 2："本季度各品类的销售占比"
- [ ] 演示示例 3："销售额前十的客户列表"
- [ ] 说明 AI 自动生成 SQL 的过程

### 第 5 步：Metabase 展示（45 秒）
- [ ] 切换到 Metabase（http://localhost:3001）
- [ ] 展示预置仪表板
- [ ] 演示拖拽创建简单图表（可选）

### 第 6 步：总结收尾（15 秒）
- [ ] 返回登录页或仪表板
- [ ] 准备进入 Q&A 环节
